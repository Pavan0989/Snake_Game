# Classic Snake Game 🐍

A feature-rich and modern take on the classic Snake game, built from scratch with pure HTML, CSS, and JavaScript. This project demonstrates core game development concepts including the game loop, collision detection, dynamic difficulty, and saving state with `localStorage`.

## ✨ Features

-   **Classic Gameplay:** A smooth and responsive snake controlled by the arrow keys.
-   **High-Score System:** Your top score is automatically saved in the browser using `localStorage`, so it persists even after you close the page.
-   **Dynamic Difficulty:** The snake's speed increases as your score goes up, providing a progressive challenge.
-   **Restart Functionality:** A clean "Game Over" screen displays your final score and allows for an instant restart.
-   **Real-time Score Tracking:** The current score is clearly displayed and updates as you eat food.
-   **Built with HTML5 Canvas:** Utilizes the Canvas API for efficient and smooth rendering of game elements.

## 🛠️ Tech Stack

-   **HTML5:** Structured the game with a `<canvas>` element.
-   **CSS3:** Styled the interface for a clean and focused user experience.
-   **Vanilla JavaScript (ES6+):** Powered all game logic, from movement and collision to scoring and state management.
-   **Git & GitHub:** Used for version control and project hosting.

## 🚀 Running the Project Locally

To run this project on your own machine, follow these steps:

1.  Clone the repository to your local machine:
    ```bash
    git clone [https://github.com/Pavan0989/Snake_Game.git](https://github.com/Pavan0989/Snake_Game.git)
    ```
2.  Navigate into the project directory:
    ```bash
    cd Snake_Game
    ```
3.  Open the `index.html` file in your favorite web browser.

## 🎮 How to Play

-   Use the **Arrow Keys (↑, ↓, ←, →)** to control the snake.
-   Eat the **red food** to grow longer and increase your score.
-   Avoid colliding with the **walls** or the **snake's own tail**!
